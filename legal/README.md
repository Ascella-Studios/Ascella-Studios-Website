# App Legal Docs

⚠️ **Do not delete this directory** — it is an automation deploy target.

The Ascella app starter kit (Phase 10 / store-automator) copies
`legal/{appname}/privacy.html` and `legal/{appname}/terms.html` here for each
app at submission time. The dynamic routes `/[appname]/privacy` and
`/[appname]/terms` serve these files.

This directory is empty between launches — that's expected.
